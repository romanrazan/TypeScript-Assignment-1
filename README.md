# TypeScript and OOP Assignment

## Assignment Overview

This assignment contains solutions to eight problems using TypeScript.
The problems cover optional parameters, union types, type narrowing,
readonly tuples, generics, interfaces, inheritance and asynchronous
operations with Promises.

All coding solutions are available in [solutions.ts](./solutions.ts).
